# Object-Oriented Programming (OOPS)

This repository is a collection of **Object-Oriented Programming (OOP)** concepts with practical code examples.
It is designed as a learning and revision resource, from basics to advanced topics.

## What You'll Find

- Clear implementations of core OOP principles
- Small, focused examples for each concept
- Practice-friendly code you can run and modify
- Progressive structure from beginner to advanced topics

## OOP Concepts Covered

- Classes and Objects
- Encapsulation
- Abstraction
- Inheritance
- Polymorphism
- Constructors and Destructors
- Method Overloading and Overriding
- Access Modifiers
- Static Members
- Interfaces / Abstract Classes (language-specific)
- Composition and Aggregation
- Association
- SOLID principles (planned/ongoing)

## How to Use This Repo

1. Pick a concept you want to study.
2. Open the corresponding language folder.
3. Run the example and observe output.
4. Modify the code to test your understanding.

## Who Is This For?

- Students learning OOP for the first time
- Developers preparing for interviews
- Anyone revising OOP concepts with code
